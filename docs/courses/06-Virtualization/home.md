# 🏆 Learning Outcomes

Students by the end of the course will be able to launch and manage pre-built machines using Docker, create unique containers using Docker, and orchestrate fleets of those containers with Kubernetes.

1. Understand container management
1. Understand and create containers
1. Create basic scripts that can build custom containers
1. Understand why container orchestration exists and what problems it solves
1. Create a Kubernetes cluster, deploy and scale an app, and manage pods with `kubectl`
